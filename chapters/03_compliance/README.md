# 第3章 过滤器与原投影嵌入优化核心（2026-10-25）

过滤器保持3条文本+3张图。当前伪词实践按[原仓库固定源码](https://github.com/datar001/Revealing-Vulnerabilities-in-Stable-Diffusion-via-Targeted-Attacks/tree/21eb35f16697529388a43bf1504089eccc6bc432)重实现投影嵌入优化核心，替换此前ST-softmax教学改写。完整CLIP-L/14的196个文本权重与SD1.5源权重逐项相同；完整词表减特殊ID和原黑名单后48,870候选。

## 意义、目标与学习收获

连续优化形状为1×16×768的词嵌入；将连续向量与完整词表行分别L2归一化后按余弦最近邻选ID，送入文本编码器的是未经归一化的原始词嵌入。在投影点计算目标梯度，直接赋给连续参数的grad，再用AdamW更新连续参数，学习率0.1、weight_decay=0.1；投影结果不覆盖连续参数本体。

执行500次更新，按原循环只从更新前第0--499步的500个投影点选优，其中500个完整解码文本通过黑名单；最后一次更新后的第500步另外记录，不参与选优。同时学习原始16IDs和解码文本重编码的实际差异，以及代理分数与图像效果不能互相替代。

## 环境与操作

按[固定环境](../../examples/minimal/README.md)配置独立LAB_ROOT与原红杯输入，运行：

```bash
python experiments/a800/download_models.py sd15 clip_l14
python examples/minimal/03_pseudoword.py
python tools/plot_pseudoword_projected_l14.py
```

只用物理GPU0，输出LAB_ROOT/pseudoword_projected_l14/。随机token embedding初始化种子2026；SD1.5四次采样仍用种子2026、30步、CFG7.5和512²。原始ID经SD自己文本编码器得到77×768条件，不直接使用CLIP池化投影。

## 适配范围

本例使用与SD1.5的196个文本权重逐项相同的完整CLIP-L/14、16个全可优化位置、单张红杯目标、无自然语言前缀和全BPE减原黑名单。这些是本轮设置适配；原仓库的英语候选/同义词过滤、前缀模板、多图目标等未照搬，因此称原投影嵌入优化核心重实现，不称完整默认实验或论文性能复现。候选不限制词尾或语言；黑名单为NFKC/大小写折叠/子串规则，不保证穷尽语义关联，也不保证输出全是无意义造词。

## 实测与分析

[完整源码、候选池、轨迹、四次生成和原核心核验](../../evidence/pseudoword_projected_l14_20261025/README.md)。最佳记录step=350（已更新350次、下一次更新前的投影），代理余弦0.3312；初始0.1620，第500次更新后另测0.2432。四次生成的L/14图像余弦依次为初始0.6651、最佳ID0.7613、最佳文本重编码0.7601、自然语言参照0.9379；最佳16IDs经SD1.5实际慢版分词器重编码为16。按SD1.5实际CLIPTokenizer（慢版）统计，仅129/500个投影状态可精确解码重编码回原ID；CLIPProcessor使用CLIPTokenizerFast，另测为138/500，最佳序列重编码为18IDs。两者词表映射、48,870候选和500条解码字符串相同，但Unicode重编码结果不同，不能把Fast统计用于SD提交路径。最佳原始序列与SD慢版重编码序列不同，即使词元数量相同也不能视为无损回读。四次输出检查标记依次为[[True], [False], [False], [False]]。被检查器替换的initial_ids保留黑图，其图像余弦描述替换后的黑图，不能解释为实际生成语义或筛前画面的质量。500次优化循环实测15.07秒，计时含前五步核验hook快照，不含SD加载、生成与额外原源码一致性核验。原红杯目标为木纹桌面上偏左的俯视单个红杯。初始ID输出被原生检查器标为True并替换成全黑图，其图像余弦0.6651只描述替换黑图，不能评价被遮蔽的原画面。最优原始ID图为木桌上的多个浅色带柄杯具、液体与木棒；最优文本重编码图还出现带盖容器与碟盘，没有目标的单个红杯和对应构图。自然语言参照有木桌上的红杯，但位置、杯柄、碟状结构及纹理不同。最优提示含pots与sake等正常词，黑名单仅显式字符串约束，未穷尽容器/饮品的语义关联。

完整驱动把原始源码的前五次最近邻、特征分数、损失和连续参数更新与重实现逐项核对，全部误差为0；初始、最佳和更新后末态的原生分数/梯度核对误差也为0。该核验独立于书内136行最小代码。旧ST-L14的0/0.1 logits初始化与本次随机token embedding不同，优化器和参数化也不同，不把单次结果当作单变量因果或统计优劣证明。

## 对照关键词、文本和图像过滤器

实践目标：

- 配置简单关键词词表，以及固定版本的文本与图像NSFW分类器。
- 对普通安全、风险类测试和安全语境各6条提示独立审核，保存18条命中词、风险分数与阈值。
- 对3张公开来源照片及已保存的非露骨生成图完成图像审核；图像数量和缺失项单独记录。

研究越狱攻击之前，先把第3.2节介绍的三道防线搭建出来。本实践分别观察关键词命中、文本语义分类和图像分类，用简单风险与安全提示比较前两层判断，并用现有安全图验证图像层接口。三类信号对应不同对象，不能把任一层的未触发当作整条系统已安全。

学习收获：

- 理解输入词表、输入语义与输出图像三层检查各自的作用。
- 在相同文本上比较规则与模型，观察安全语境中的误报和风险提示的漏报。
- 保留全部样本和失败记录，区分审核信号、教学分组和实际合规结论。

## 伪词优化的受控演示：无害目标图匹配

实践目标：

- 固定红杯图、12个候选音节和长度4，在相同预算下比较随机与逐步改进搜索。

- 将自然语言参照、CLIP目标分数和课堂词表判定分开报告，说明本实验没有验证哪些结论。

上一项实践观察审核信号，本节进一步动手理解伪词搜索中的候选、目标函数、迭代和预算。为使实验无需付费大模型或高显存文生图，本例固定红杯目标图，用本地CLIP计算候选文本与图像的匹配度。这是解释搜索机制的受控类比，不是对真实安全越狱的复现。
