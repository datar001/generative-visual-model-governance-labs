# 实验记录与作业提交

每个实验报告依次写：实践意义、目标、预备知识、环境与输入、操作、全部结果、分析与局限。未执行的步骤标记未执行，预期效果与实测结果分开。

建议字段：运行ID、问题、模型标识及修订号、代码提交号、提示、种子、采样器、步数、引导强度、图像尺寸、精度、设备、依赖版本、输入来源、授权记录标识、输出路径、检查器信号、失败状态、人工观察。不要将密码或令牌写入记录。授权材料保存在合适位置，公共报告只引用记录标识。

每次运行日志保存于results/runs/。脚本输出目录为results/中的对应任务目录；如重复运行可能覆盖同名图像，应先复制一份到按运行ID命名的归档目录。章节练习中的变量修改也要同时保留原始配置。

第7章人工复核时，将自动标签与人工reviewed_label分列；允许feminine、masculine、uncertain、no_face、multiple、failed、unreviewed。空白视为未复核。汇总命令：

```powershell
python chapters/07_fairness/summarize.py path/to/reviewed.csv
```

evidence/分别保存有日期的历史真实证据与后续新运行结果；第3章filter_comparison_20261021为本轮实际审核。引用时注明对应运行。模型实验未完成的章节不能因代码通过语法检查就被标记为已实测。
