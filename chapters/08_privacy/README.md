# 第8章 肖像隐私保护

[习题](exercises.md) · [参考答案](answers.md)

## 给肖像加入保护扰动

### 为什么做

对肖像加入扰动后，识别器分数降低并不自动说明定制生成已失效。本实践把防护拆为可见质量、当前编码器特征变化、JPEG后保留情况和实际定制对照四层，帮助读者建立完整的验证链。

### 实践目标（应交付什么）

- 对有授权、单人且对齐的人脸输入施加有限幅度扰动，保存原图、保护图及JPEG副本。
- 比较同一编码器下压缩前后的余弦相似度，并记录扰动预算。
- 在同一IP-Adapter管线和种子下，对三类参考图生成对照，分别评估身份保持和图像质量。

### 完成后应掌握什么

- 理解受约束的特征优化方向，以及像素范围和预算投影的作用。
- 区分编码器层代理指标与肖像定制层的实际效果。
- 认识压缩、未知识别器和定制模型迁移对防护结论的影响。

### 环境和输入

先提供有权用于实验的单人对齐人脸inputs/face.png。特征实验使用独立FaceNet环境：PyTorch 2.2.2、torchvision 0.17.2、facenet-pytorch 2.6.0与Pillow 10.2.0。定制对照切换回生成环境，使用SDXL与IP-Adapter权重，需足够显存/内存。两套环境通过保存图像衔接，不能混装依赖。

环境安装见[环境说明](../../docs/environment.md)。先从仓库根目录运行：

```powershell
python tools/check_environment.py --profile privacy
python tools/run.py 08 --case features --dry-run
```

### 操作步骤

1. 在特征环境运行扰动脚本，检查原图、保护图和压缩图，记录预算8/255、步长1/255及40步优化。
2. 逐一核对余弦分数、像素可见差异及JPEG处理。修改预算时另存实验条件，不能覆盖基线。
3. 在生成环境运行定制脚本，三种输入使用相同提示、种子及管线；再用独立编码器和不同提示补充迁移复测。

在环境确认后执行：

```powershell
python tools/run.py 08 --case features
```

完成特征实验后，在生成环境继续执行：

```powershell
python tools/run.py 08 --case customize
```

核心程序：[features.py](features.py)。运行结果位于仓库根目录results/，每次运行日志与环境摘要位于results/runs/。

### 预期效果

得到原图、保护图、JPEG副本、特征分数及三张定制生成图。相似度下降只说明当前编码器受扰动。原/保护/压缩图的定制结果要单独观察，不能用特征分数代替实际生成证据。本实现不等同于Anti-DreamBooth、IDProtector或TED完整复现。

### 本地实测状态

尚未提供授权人脸，也未完成特征优化或定制实测。随仓库提供两阶段入口及记录格式；不使用无授权照片填充实验，不预填身份防护成功率或相似度。

### 结果分析与提交物

联合检查视觉质量、当前及独立编码器的分数、JPEG变化和定制图。若仅一个优化过的编码器受影响，而定制结果仍保持身份，就应报告迁移失败，不能把局部代理指标写成普遍保护效果。
