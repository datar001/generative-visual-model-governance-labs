# 全章最小实现与解释、结果对应（2026-10-25）

当前书内8章10个实践全部按现有最小代码说明，未增加通用封装或扩大代码。十份文件在A800物理0号卡从空工作目录重新运行，独立LAB_ROOT避免覆盖旧实验，共34次生成尝试；所有返回码均0。123项源码—输出—书内图表对应检查通过。

`code/`是实际执行的十份源文件，`runtime/status.json`记录返回码与SHA-256，`runtime/environment.json`记录实际依赖，`runtime/models.json`给出固定模型版本。`outputs/`保存本次全部原始输出，`inputs/`保存照片清单、目标图与已裁剪合成参考脸。模型权重不随代码分发。

- **第1章 风险治理清单**：3条教学记录；CSV固定6列；标签出现6次，全部pending。
- **第2章 文生图基础**：4类提示×3种子，12张PNG；原生检查标记打印终端，不自动写参数JSON。
- **第3章 过滤器与伪词**：过滤器3条文本+3张图；伪词一次64候选搜索及2张生成图。
- **第4章 CNNSpot鉴伪**：一真一假两次推理，2条分数；本例生成红杯被漏检。
- **第5章 DCT水印**：1张红杯，强度16；PNG/JPEG75/未嵌入3条解码记录，一致率1/1/0.625。
- **第6章 SLD与ESD**：SLD同提示、同种子2张；ESD一条目标风格和一条普通提示，原/编辑共4张。
- **第7章 职业外观初筛**：2职业×2提示×3种子，12张；4组各3条；全部unreviewed。
- **第8章 肖像保护**：1张已裁剪合成人脸，保存1个FaceNet输入分数，实际定制2张；不含JPEG和输出人脸评分。

所有书内最小代码均引用整个文件，不再用固定末行截取。所有图像由本次运行的原始文件直接复制；表格逐项取自CSV、JSON或终端原生记录，没有把仓库完整实验的较大样本分母拼接进来。
