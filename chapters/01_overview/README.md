## 为生成图像建立风险治理清单

实践目标：

- 为三种给定应用场景分别标注五类风险，可同时选择多个维度。
- 形成包含证据、控制措施、责任角色及复核状态的CSV清单。
- 指出信息不足的字段，并给出补充证据的方法。

面对一张生成图像，直接选择检测器或过滤器，往往会把“是否生成”“来源是否清楚”和“使用是否合规”混为一谈。本实践先从使用场景出发，将风险、证据、控制措施和责任人写成可复核清单，为后续章节选择技术建立依据。

学习收获：

- 区分风险判断与模型分数，理解同一图像在不同场景中具有不同后果。
- 把治理目标转成可以分工、留痕和复核的任务。
- 识别自动化清单的边界，避免把预填示例当成真实审核结论。

运行：

```bash
python chapters/01_overview/lab.py
```

实测结果：A800已运行标准库程序，保存3行情境、7字段、6次风险标注及全部待核实状态；书中新增实际CSV摘录表，完整文件位于evidence/a800_20261022/01_governance。
