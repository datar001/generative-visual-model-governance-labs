## 比较SLD开启与关闭

### 为什么做

推理阶段防御会改变生成轨迹，其效果不应只被归纳为“有害内容变少”。本实践先用同一模型和初始随机性比较SLD关闭与开启，让读者观察干预位置、内容变化和输出检查信号之间的关系。

### 实践目标

1. 对作者指定的成人风险提示和衣着完整的正常肖像提示，分别设置SLD关闭与STRONG，建立四条件对照。
2. 对齐模型、提示、种子和步数，分列引导模式与输出检查标志。
3. 记录语义、主体、服装与构图的变化，允许出现“未观察到差异”。

### 学习收获

1. 理解推理引导和生成后检查器属于不同环节。
2. 使用成对实验评估干预，同时关注正常内容保持。
3. 区分课堂观察与有独立风险标签的安全性能评估。

### 环境与输入

使用第2章生成环境，另下载Safe Stable Diffusion管线权重。SLD管线在本书固定的Diffusers 0.32.2中使用，不能把新版接口变化视为实验结果。显卡需容纳推理模型；低显存设备可使用已配置的注意力切片与CPU卸载。 风险提示采用作者提供的原句，woman限定为成年人；第二个提示为衣着完整的正式肖像，保留输出检查器。

### 操作步骤

1. 检查模型、SafetyConfig和环境版本，保留输出检查器。
2. 对每个提示分别设置引导关闭和STRONG，其余参数相同，保存四张图与标志。
3. 按主体、语义、服装、背景及失败状态逐项对照；随后可增加WEAK或MAX作为拓展，另建实验条件。

运行前阅读[环境说明](../../docs/environment.md)。

```powershell
python tools/run.py 06 --case sld --dry-run
python tools/run.py 06 --case sld
```

核心程序：[sld.py](sld.py)。

### 预期效果

得到风险/正常两种提示与off/STRONG两种模式的对照记录；输出检查器可能替换结果，需要分别记录生成条件和检查标志，不能把最终图片缺失或被替换直接归功于SLD。

### 本地实测状态

本轮完成作者指定风险提示与正常对照的配置更新，未运行或展示裸露图像生成；因此没有本机色情抑制效果或拦截率结论。

### 结果分析

若要报告安全性，应先定义风险类别、审核依据和独立测试集，同时测正常提示的语义与质量保持。本案例只负责建立受控观察方法。

## 加载预训练ESD权重观察风格擦除

### 为什么做

概念擦除改变的是模型参数。本实践直接加载作者公开的ESD-x风格擦除权重，比较相同条件下原模型与编辑模型的输出，把学习重点放在权重配套、目标行为变化与无关内容保持，不再要求学员训练ESD。

### 实践目标

1. 核对官方Van Gogh ESD-x权重与SD 1.4基础模型的对应关系，保存版本与文件哈希。
2. 对目标风格和普通内容各作一次原模型/擦除模型配对生成，保存四张图及参数。
3. 说明目标风格变化、正常内容保持与观察边界，不能由少量示例推断普遍擦除效果。

### 学习收获

1. 区分完整UNet权重、LoRA适配器和完整生成管线；官方文件替换的是基础模型的UNet参数。
2. 用相同基础组件、提示、种子和采样设置进行配对推理，避免把更换基础模型的差异当成擦除效果。
3. 从输出观察理解ESD参数编辑的作用，不再编写教师网络、优化器或反向传播训练循环。

### 环境与输入

使用生成环境和官方公开的diffusers-VanGogh-ESDx1-UNET.pt，配套CompVis/stable-diffusion-v1-4。该文件是完整Diffusers UNet参数，不是LoRA，也不能随意搭配SD 1.5或SDXL。代码固定基础模型修订号，校验权重SHA-256并严格加载。只做推理，CPU或CUDA均可；低显存设备采用注意力切片与逐层CPU卸载，不再同时保留教师、学生和优化状态。权重下载入口与校验信息在配套目录，权重不随书稿分发。

### 操作步骤

1. 从官方发布页下载指定风格擦除权重并校验哈希，准备与其配套的SD 1.4基础模型。
2. 先用原模型生成目标风格和普通内容，再严格加载官方UNet权重，对相同提示、种子与采样设置再次生成。
3. 逐项观察风格、主体和普通内容的变化，保留输出检查标志与失败记录；拓展时增加其他提示和种子，不只挑选变化明显的图片。

运行前阅读[环境说明](../../docs/environment.md)。

```powershell
python chapters/06_defense/esd_support.py --download
python tools/run.py 06 --case esd --dry-run
python tools/run.py 06 --case esd
```

核心程序：[esd.py](esd.py)。

### 预期效果

得到目标风格与普通内容在base/esd两条件下的四张图，以及记录模型版本、权重哈希、提示和参数的observations.json。不产生训练损失、训练日志或另行训练的模型；效果可能受提示和种子影响。

### 本地实测状态

官方权重已完成下载、SHA-256校验及与SD 1.4的严格参数键/形状检查。本机CPU低分辨率单步四条件流程已完成，保留全部输出和检查标志；目标风格提示在两模型上均被输出检查器替换，不能据此比较风格效果。默认课堂设置下的擦除效果尚未完成验证。

### 结果分析

同时观察目标风格是否减弱和普通内容是否保持。视觉变化可帮助理解权重编辑的作用，少量示例不能证明所有表达都已被擦除；加载成功也不等于效果验证完成。

## 官方权重与本地设置

[ESD官方发布页](https://erasing.baulab.info/weights/esd_models/)及[权重说明](https://erasing.baulab.info/weights/esd_models/README.txt)明确：本章选取Van Gogh风格ESD-x完整UNet权重，与SD 1.4配套。参考旧版发布格式，避免把新版本safetensors增量格式混用。模型文件不随仓库分发，遵守原模型许可。

已有本地文件时设置ESD_WEIGHTS；已缓存基础模型时设置ESD_BASE_MODEL。默认20步、512像素、种子2026，ESD_STEPS和ESD_IMAGE_SIZE可用于另行标记的流程检查。输出JSON保存实际设置；较低分辨率/步数的检查不应写成默认配置效果。

SLD测试输入采用作者指定的风险提示文本，代码保留输出检查器；本轮没有执行或展示裸露图像生成，不能据配置更新声称色情抑制已经验证。

[ESD实际流程检查及全部输出](../../evidence/esd_pretrained_20261021/README.md)。可用ESD_DEVICE=cpu指定CPU，用ESD_OUTPUT_DIR另建输出目录；64像素单步检查不是默认20步/512像素的效果验证。
