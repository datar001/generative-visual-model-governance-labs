# 第5章：图像水印

完整环境和数据准备见 [全章运行说明](../../experiments/a800/README.md)。运行前设置独立的 `LAB_ROOT`，实际结果保存于其 `results/`；书中只展示固定样例，完整原图保留在实测结果包。

## 嵌入水印并测试压缩影响

实践目标：

- 在9张输入图上分别以三个强度嵌入16位循环消息，保存原图与带水印图。
- 对三档JPEG副本解码，计算比特恢复率及相对原图的PSNR。
- 改变嵌入强度并记录可见失真、恢复变化及实验边界。

水印不能只看“加进去以后还能不能看见”。它同时涉及消息能否恢复、图像失真大小以及未嵌入图是否被误判。本实践用透明的频域教学实现，把嵌入、传播处理和恢复连成闭环，认识这些目标之间的取舍。

学习收获：

- 理解分块DCT系数差如何承载一位信息以及重复嵌入如何汇总证据。
- 区分消息恢复率、检出置信度与误报率，避免混用指标。
- 用同图对照分析不可见性与稳健性的取舍。

运行：

```bash
python experiments/a800/watermark.py
```

实测结果：A800完成9图×3强度×8条件=216条水印记录。当前PNG/JPEG/缩放/噪声全部16位恢复；裁切后恢复率约一半，9图均不能完整恢复；9个独立未嵌入负对照无全16位匹配。
