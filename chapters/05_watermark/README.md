## 嵌入水印并测试压缩影响

### 为什么做

水印不能只看“加进去以后还能不能看见”。它同时涉及消息能否恢复、图像失真大小以及未嵌入图是否被误判。本实践用透明的频域教学实现，把嵌入、传播处理和恢复连成闭环，认识这些目标之间的取舍。

### 实践目标（应交付什么）

- 在同一输入图上嵌入16位循环消息，保存原图与带水印图。
- 对三档JPEG副本解码，计算比特恢复率及相对原图的PSNR。
- 改变嵌入强度并记录可见失真、恢复变化及实验边界。

### 完成后应掌握什么

- 理解分块DCT系数差如何承载一位信息以及重复嵌入如何汇总证据。
- 区分消息恢复率、检出置信度与误报率，避免混用指标。
- 用同图对照分析不可见性与稳健性的取舍。

### 环境和输入

使用Python 3.10、NumPy 1.26.4和OpenCV 4.10.0，可在CPU运行。优先使用第2章生成的红杯图；若缺失，脚本生成明确标注的程序测试图，便于独立跑通流程。两种输入的结果应分开记录。

环境安装见[环境说明](../../docs/environment.md)。先从仓库根目录运行：

```powershell
python tools/check_environment.py --profile watermark
python tools/run.py 05 --dry-run
```

### 操作步骤

1. 记录输入图来源、消息种子2026、嵌入强度24和图像尺寸，执行基线嵌入。
2. 检查原图与带水印图，对照原始16位消息与PNG解码消息，再读取三档JPEG的逐位解码、恢复率及PSNR结果。
3. 在独立输出目录把强度改为12或36重复实验；扩展裁剪对照时另记块对齐变化，不能覆盖基线文件。

在环境确认后执行：

```powershell
python tools/run.py 05
```

核心程序：[lab.py](lab.py)。运行结果位于仓库根目录results/，每次运行日志与环境摘要位于results/runs/。

### 预期效果

得到input.png、marked.png、三张JPEG图、scores.csv和decoding.json（原始及解码比特串）。16位消息循环写入块中，恢复率是正确位占比；PSNR是像素失真指标。此代码不复现Tree-Ring、HiDDeN或SDXL内置水印，也不是生产级方案。

### 本地实测状态

已有本机单图实测：在第2章红杯生成图、强度24下，JPEG质量100、75、40的恢复率均为1.00，对应PSNR约37.86、33.91、31.65 dB。结果仅适用于这张输入和当前实现，原始图片与CSV随书保留。 本轮复测保留原始16位消息1001000010111110，PNG图和JPEG质量100、75、40均解码为相同比特串，16/16位一致。原图、含水印PNG、JPEG副本及原CSV与本轮前逐文件SHA-256相同；解码仅恢复消息，不重建无水印原图。

### 结果分析与提交物

观察细纹、平坦区和边缘，不能只凭较高PSNR断言不可见。再用未嵌入图和独立消息测试误报；仅在一张图上恢复16位消息，不能得到统计置信度或跨图性能保证。
