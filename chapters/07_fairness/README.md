# 第7章 公平性去偏

[习题](exercises.md) · [参考答案](answers.md)

## 测量职业提示下的呈现偏差

### 为什么做

公平性讨论需要把“看起来有偏差”转成可检查的采样、标注和统计流程。职业提示能展示默认呈现与显式条件之间的差别，但自动识别器本身也可能有偏差。本实践将生成、初步标注、人工复核和含不确定项的统计分开。

### 实践目标（应交付什么）

- 预先确定10种职业、20个种子和两种提示模式，共生成400张图像。
- 保存逐图来源、自动标签、人工复核标签及无法判定原因。
- 按职业和提示模式报告全部样本、可判定样本、不确定项及失败项，比较分布。

### 完成后应掌握什么

- 区分可观察的视觉呈现与人的真实身份，不把二元候选标签当作身份事实。
- 理解分母、识别器误差和样本量如何影响公平性结论。
- 认识显式加入属性词只是局部干预对照，不能代替系统性去偏。

### 环境和输入

使用第2章生成环境，另需CLIP零样本图像分类模型。完整设计含400次生成，先用少量样本确认路径、存储和设备可用，但不能将小样本试跑当作完整评估。人工标签单独保存，允许不确定、无人脸、多人物和生成失败。

环境安装见[环境说明](../../docs/environment.md)。先从仓库根目录运行：

```powershell
python tools/check_environment.py --profile generation
python tools/run.py 07 --dry-run
```

### 操作步骤

1. 固定职业集合、提示模板和20个种子，运行两种模式；不根据生成结果临时删职业或换样本。
2. 把自动分数视为待复核建议，人工检查并填写reviewed_label与原因；缺失审核的行保持未复核。
3. 使用统计脚本按职业、模式汇总全部行及已复核类别。先报告完整性和不确定项，再比较可判定样本中的比例。

在环境确认后执行：

```powershell
python tools/run.py 07
```

核心程序：[lab.py](lab.py)。运行结果位于仓库根目录results/，每次运行日志与环境摘要位于results/runs/。

### 预期效果

得到400张图与逐图CSV。程序的0.65阈值只是初步分流设置，需人工校验，不能自动建立真实身份标签。统计表应同时包含总数、未复核、失败、不确定与可判定分母，避免只展示方便比较的两类比例。

### 本地实测状态

400次生成、人工复核与统计尚未完成。随仓库提供人工复核模板及离线统计工具；工具的小规模示例仅验证分母处理，不代表模型实际公平性结果。

### 结果分析与提交物

20个样本容易受随机性影响。即便某个职业出现12比8，也需要不确定区间、更多种子和明确的目标分布；性别呈现对照不能替代年龄、肤色、文化及交叉群体的分析。
