# 第8章：肖像隐私保护

完整环境和数据准备见 [全章运行说明](../../experiments/a800/README.md)。运行前设置独立的 `LAB_ROOT`，实际结果保存于其 `results/`；书中只展示固定样例，完整原图保留在实测结果包。

## 给肖像加入保护扰动

实践目标：

- 对三个合成成人单人脸参考输入施加有限幅度扰动，保存原图、保护PNG与JPEG副本。
- 比较同一编码器下压缩前后的余弦相似度，并记录扰动预算。
- 在同一IP-Adapter管线下，对三类参考图和三个种子生成27张正式对照，分别观察人脸保持与图像质量。

对肖像加入扰动后，识别器分数降低并不自动说明定制生成已失效。本实践把防护拆为可见质量、当前编码器特征变化、JPEG后保留情况和实际定制对照四层，帮助读者建立完整的验证链。

学习收获：

- 理解受约束的特征优化方向，以及像素范围和预算投影的作用。
- 区分编码器层代理指标与肖像定制层的实际效果。
- 认识压缩、未知识别器和定制模型迁移对防护结论的影响。

运行：

```bash
python experiments/a800/privacy.py
```

实测结果：A800使用3个合成成人参考脸完成40步有界扰动及原/保护/JPEG三条件×3种子=27张正式定制图；三条件均9/9单脸可判读，全部未触发输出检查。保留构图预实验与6组正常输入诊断，不将特征下降等同防护成功率。
