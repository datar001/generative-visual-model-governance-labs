# 第2章：生成式视觉大模型基础

完整环境和数据准备见 [全章运行说明](../../experiments/a800/README.md)。运行前设置独立的 `LAB_ROOT`，实际结果保存于其 `results/`；书中只展示固定样例，完整原图保留在实测结果包。

## 生成第一张图像

实践目标：

- 用三个固定种子分别生成红杯和蓝杯，保存六张配对图、原始提示、参数与输出检查标记。
- 建立最小实验记录，写明模型、设备、精度、随机种子和软件版本。
- 比较颜色、背景、把手及杯内状态，区分预期变化与伴随变化。

理解文生图流程，不能只记住文本编码器、去噪网络和解码器的名称。通过完成一次可记录的生成，并只改变提示中的颜色词，可以把抽象模块与可观察输出对应起来，也为后续鉴伪、水印和治理实验准备共同输入。

学习收获：

- 将“提示词—条件编码—去噪—解码”的概念链与实际调用对应。
- 理解固定种子和单变量对照各控制什么，知道固定种子不等于局部编辑。
- 识别下载失败、显存不足和非有限数值等运行问题，避免把黑图当作有效样本。

运行：

```bash
python experiments/a800/generation.py
```

实测结果：A800完成12次512×512、30步生成，其中红/蓝杯3组配对共6图，另有3张风景和3张合成成人头像。全部输出检查未触发，书中展示完整的三组颜色/种子对照。
