# 第3章 过滤器与16词元伪词优化（2026-10-25）

本章过滤器仍为3条文本与3张普通图的逐项观察；伪词实践改为固定红杯、16个真实BPE词元、500次Adam更新，在A800物理0卡实跑。

## 为什么做、目标与学习收获

学习从离散词元、连续概率与直通梯度到实际图像生成的完整链路。冻结CLIP权重，24个中性音节构成白名单，排除cup/mug/teacup及杯器、饮品、颜色和材质关联词；优化16个位置，保存501个状态，区分初始、最终和历史最优。

## 环境与操作

先按[最小实现准备](../../examples/minimal/README.md)下载固定模型并复制红杯目标图，再运行：

```bash
python examples/minimal/03_filters.py
python examples/minimal/03_pseudoword.py
python tools/plot_pseudoword16.py
```

GPU代码在导入Torch前固定0卡。伪词输出位于LAB_ROOT/pseudoword16_500/；绘图为可选后处理。

## 当前实测与分析

[82行源码、501条轨迹、词表、输入与全部三张生成图](../../evidence/pseudoword16_500_20261025/README.md)。第465步代理分数最高0.2288，初始0.1942，最终第500步0.2209。生成图与目标图的余弦：初始0.3570、历史最优0.4488、自然语言参照0.9444。初始与最优仍为人物场景，没有生成红杯；自然语言参照有红杯但未复原目标布局。自然语言只作不参与优化的参照，含目标词且不受16-token白名单约束；不能据代理分数提升声称目标重建或真实越狱成功。

# 第3章：内容合规性漏洞

完整环境和数据准备见 [全章运行说明](../../experiments/a800/README.md)。运行前设置独立的 `LAB_ROOT`，实际结果保存于其 `results/`；书中只展示固定样例，完整原图保留在实测结果包。

## 对照关键词、文本和图像过滤器

实践目标：

- 配置简单关键词词表，以及固定版本的文本与图像NSFW分类器。
- 对普通安全、风险类测试和安全语境各6条提示独立审核，保存18条命中词、风险分数与阈值。
- 对3张公开来源照片及已保存的非露骨生成图完成图像审核；图像数量和缺失项单独记录。

研究越狱攻击之前，先把第3.2节介绍的三道防线搭建出来。本实践分别观察关键词命中、文本语义分类和图像分类，用简单风险与安全提示比较前两层判断，并用现有安全图验证图像层接口。三类信号对应不同对象，不能把任一层的未触发当作整条系统已安全。

学习收获：

- 理解输入词表、输入语义与输出图像三层检查各自的作用。
- 在相同文本上比较规则与模型，观察安全语境中的误报和风险提示的漏报。
- 保留全部样本和失败记录，区分审核信号、教学分组和实际合规结论。

运行：

```bash
python experiments/a800/filters.py
```

实测结果：A800完成18条文本和31张图像审核。普通安全/风险/安全语境各6条，关键词拦截0/4/5条，文本模型拦截2/6/4条；图像31张均未触发，未估计风险召回率。

## 伪词优化的受控演示：无害目标图匹配

实践目标：

- 固定红杯图、12个候选音节和长度4，在相同预算下比较随机与逐步改进搜索。
- 对三个种子分别运行16次和64次预算，保存480次候选查询及每次最佳分数。
- 将自然语言参照、CLIP目标分数和课堂词表判定分开报告，说明本实验没有验证哪些结论。

上一项实践观察审核信号，本节进一步动手理解伪词搜索中的候选、目标函数、迭代和预算。为使实验无需付费大模型或高显存文生图，本例固定红杯目标图，用本地CLIP计算候选文本与图像的匹配度。这是解释搜索机制的受控类比，不是对真实安全越狱的复现。

学习收获：

- 理解伪词字符串经过分词器拆分后进入冻结的文本编码器，候选音节不等于单个词元。
- 理解同一起点、相同查询预算和完整搜索轨迹对公平比较的作用。
- 区分图文表示匹配、生成图像的实际效果以及真实安全越狱的判定依据。

运行：

```bash
python experiments/a800/pseudoword.py
```

实测结果：A800完成12组/480次无害伪词查询，并把6个最优候选与自然语言参照实际生成7图；保存代理分数及生成失败的语义案例，不报告真实越狱成功率。
