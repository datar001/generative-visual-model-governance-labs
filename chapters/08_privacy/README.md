# 第8章 匹配定制入口的肖像保护

当前方法直接改变IP-Adapter Plus Face实际使用的CLIP倒数第二层与Resampler条件，在3/255像素预算内比较原图、随机噪声和优化保护。FaceNet只评价输出身份相似性，不参与保护优化。全部公开输入和定制输出均为合成成人肖像。

## 两个运行入口

先按[环境与输入准备](../../examples/minimal/README.md)设置独立的`LAB_ROOT`。

| 入口 | 作用 | 输出检查器 | 结果目录 |
|---|---|---|---|
| [书内主代码](../../examples/minimal/08_privacy.py) | 优化并保存三种参考PNG，再生成9张定制图 | 开启 | `$LAB_ROOT/minimal_examples_20261025/08_privacy/` |
| [配对控制代码](../../examples/controls/08_privacy_checker_off.py) | 读取主入口已保存的三张PNG，仅重新生成与评分 | 关闭 | `$LAB_ROOT/privacy_checker_off_20261025/` |

```bash
python examples/minimal/08_privacy.py
python examples/controls/08_privacy_checker_off.py
```

控制入口读取主结果目录中的`original.png`、`random.png`和`protected.png`，不重新优化或重采样扰动。将两次结果分目录保存，才能判断变化来自保护输入还是输出检查器。

主入口使用配套160×160合成头像，120步动量更新，动量0.9；前90步步长0.5/255，后30步0.25/255。优化采用fp32，前向使用真实PIL/CLIP预处理，反向用可微双三次近似；保存PNG后重新读取，在实际fp16生成路径测量和定制。三种输入固定SD1.5、IP-Adapter Plus Face强度0.3、同一提示、种子2026/2027/2028、30步、CFG5和512×512输出，共9张。

## 先区分检查器，再比较保护

[主入口正式记录](../../evidence/privacy_ip_adapter_20261025/README.md)保留检查器开启的结果。保护PNG的PSNR为39.71dB，实际Resampler条件余弦为-0.2076；相同最大像素预算的随机图分别为43.15dB和0.9732。相同最大预算不等于相同扰动能量。

| 检查器开启：输入 | 可评分/尝试数 | FaceNet输出身份余弦均值 |
|---|---:|---:|
| 原图 | 3/3 | 0.5419 |
| 随机3/255 | 3/3 | 0.6215 |
| 优化保护3/255 | 2/3 | 0.1083 |

保护组种子2026被检查器替换为黑图，应记为缺失，不能给0分后平均。若只比较三组共同可评分的2027/2028两个种子，原图/随机/保护均值为0.4398/0.5425/0.1083，三组分母均为2。该配对统计与上表各组全部可评分统计应分别标明。

[关闭检查器的配对重跑](../../evidence/privacy_checker_off_20261025/README.md)复用完全相同的参考PNG，只设置`safety_checker=None`和`requires_safety_checker=False`。9张均为单脸可评分，结果为：

| 检查器关闭：输入 | 可评分/尝试数 | FaceNet输出身份余弦均值 |
|---|---:|---:|
| 原图 | 3/3 | 0.5419 |
| 随机3/255 | 3/3 | 0.6215 |
| 优化保护3/255 | 3/3 | 0.0581 |

原来未被替换的8张与此次逐像素相同；保护组2026恢复为实际肖像，身份余弦-0.0423，另两张为0.1870和0.0296。控制结果中的检查标记`null`表示没有执行检查，不能写成检查器判定安全。上表0.0581与开启时0.1083的分母不同，差异来自恢复一张输出，不表示重新优化使保护变强。

## 如何读对照图

关闭检查器证据页的三列依次为原图、随机噪声和优化保护；首排是参考输入，后三排按相同种子配对。先看参考头像是否仍可用，再逐行比较输出是否保持原参考身份。随机列用于判断一般加噪是否产生同样变化；保护目标是削弱身份复现，不要求生成失败或变成黑图。

本轮优化保护的输出身份余弦较低，支持其在这个头像、提示和管线下有效。条件余弦和FaceNet余弦均不是概率或保护成功率；只有一个主参考头像和三个种子，不能外推一般保证。独立扩展中JPEG75后的均值回升至0.6175，显示压缩稳健性不足；新头像、新提示和适配器强度的扩展设置见[完整验证记录](../../evidence/privacy_ip_adapter_20261025/README.md)，不与本节9张混用分母。
