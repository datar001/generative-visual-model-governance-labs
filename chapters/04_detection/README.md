## 4.6 动手实践：用CNNSpot学习空间域CNN鉴伪

### 为什么做

本实践把第4.2节的空间域鉴伪方法落到可运行的经典CNNSpot检测器。学员先理解“像素特征—二分类分数—阈值判断”的流程，再用JPEG对照观察生成痕迹变化，认识训练范围与泛化边界。

### 实践目标

1. 加载CNNSpot官方公开权重，说明ResNet-50单输出二分类器与生成类分数的含义。
2. 对有来源记录的真实照片和第2章生成图分别检测原始输入及三档JPEG副本，保存八组分数。
3. 在固定0.5阈值下标记预测与来源是否一致，解释压缩影响和漏检现象。

### 学习收获

1. 掌握全局图像信号中的空间域CNN监督二分类：RGB图像经ResNet-50提取特征，单个logit经sigmoid转为生成类分数。
2. 固定权重和预处理，通过同图对照分析JPEG影响；区分原始输入与质量100的重编码副本。
3. 区分模型分数、来源标签和事实真实性；理解在ProGAN上训练的检测器不保证识别扩散模型图像。

### 环境与输入准备

使用Python 3.10、PyTorch 2.5.1、TorchVision 0.20.1和Pillow，采用CPU单精度推理。CNNSpot采用真实LSUN照片与ProGAN生成图监督训练，使用模糊和JPEG增强。本实践固定官方blur_jpg_prob0.5权重，RGB转张量后按ImageNet均值/标准差归一化；沿用官方演示的全图方式，不缩放、不裁剪。配套输入为Rachel Michetti以CC0提供的scikit-image咖啡照片，以及第2章实际生成的红杯图。权重下载、SHA-256校验和输入来源均在配套目录记录。

### 操作步骤

1. 按配套说明下载并校验权重，核对两张输入的来源和哈希；来源标签独立于模型输出。
2. 加载单输出ResNet-50并切换评估模式，先检测原始输入，再检测JPEG质量100、75、40的副本。
3. 记录生成类分数与固定阈值预测，逐图比较四种条件；不得根据这两张图调整阈值以迎合结果。

先安装 [环境说明](../../docs/environment.md) 中的 PyTorch/TorchVision/Pillow，然后从仓库根目录运行：

```powershell
python chapters/04_detection/cnnspot_support.py --download
python tools/run.py 04 --dry-run
python tools/run.py 04
```

权重约282 MB，下载到被Git忽略的results/detection_weights/。已有本地文件可设置环境变量CNN_SPOT_WEIGHTS；SHA-256不符会停止。核心程序为[lab.py](lab.py)，中文注释解释推理流程；辅助程序只做权重校验和证据记录。无需LLM API或GPU。

### 预期效果

得到八组生成类分数、对应来源与预测，以及六张JPEG副本。分数越大越倾向生成类；0.5仅为固定教学阈值，分数未经本实验校准，不能当作来源或新闻事件真实性的证明。

### 本地实测

本机CPU单精度实测八组均完成。真实咖啡照片四种条件的生成类分数均小于0.000001，均判为真实；生成红杯图的原始、JPEG质量100、75、40分数依次为0.000229、0.000391、0.001347、0.009902，也均判为真实，出现漏检。该例说明在ProGAN数据上训练的经典检测器可能无法识别扩散模型输出，不能把两图示例汇总为通用准确率。

### 结果分析与提交

先比较同图的压缩条件，再结合独立来源记录辨认误报或漏报。本例生成图分数随压缩上升，但仍低于阈值，不能推断压缩必然有助于鉴伪。两类输入的内容和尺寸也不同，不能归因出真假类别的普遍差异。扩展评估须使用多来源样本及独立验证集，并把同一原图的所有变体放在同一划分。
