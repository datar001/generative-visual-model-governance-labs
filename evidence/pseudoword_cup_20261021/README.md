# 无害红杯目标伪词匹配实测（2026年10月21日）

固定红杯图、12个伪词音节、长度4，种子2026/2027/2028，预算16/64；每种配置比较随机与逐步改进搜索，共12组、480次候选逻辑查询，另有1条自然语言参照。相同种子起点相同；大预算保留小预算搜索前缀。缓存复用后实际编码379条文本（含自然语言参照）。本机CPU总用时约26.16秒，LLM API调用为0。

自然语言参照CLIP分数为0.3244；64次预算的逐步改进结果均值约0.2187。分数并未达到参照水平。全部候选通过的只是排除red/cup的课堂词表，这两个词没有风险含义。本例没有测试真实安全过滤、没有运行文生图，也不能给出真实越狱成功率。

trace.csv保留全部候选与当前最佳分数；summary.csv保留每组最终结果，aggregate.json为三个种子的描述性均值与样本标准差。settings.json保存输入、模型修订号、代码与图片哈希和实际导入版本；model_snapshot.json记录权重来源与哈希。原始运行日志保存在整书audit目录。
