# 第4章 生成图像鉴伪

[习题](exercises.md) · [参考答案](answers.md)

## 检测真实图、生成图及其压缩版本

### 为什么做

鉴伪方法在原始图上给出的高分，不一定能直接迁移到传播后的图像。通过对同一真实图和生成图施加相同JPEG处理，再查看检测器全部标签分数，可以认识输入变化、模型训练范围和结论强度之间的关系。

### 实践目标（应交付什么）

- 准备有来源记录的真实照片与第2章生成图，建立两类输入。
- 为每类输入保存原始图和三档JPEG副本，记录完整检测分数。
- 分析压缩前后分数变化，并把来源标签与检测器预测分开保存。

### 完成后应掌握什么

- 将模型输出分数与事实真实性区分，识别模型适用范围。
- 设计成对对照，控制输入尺寸、编码流程和检测模型。
- 知道为何两张图的示例不能支持通用准确率或阈值结论。

### 环境和输入

使用生成环境中的Transformers与Pillow，检测器可在CPU运行。准备来源明确、有权使用的inputs/real.jpg和第2章cup_0.png。使用历史公开基线umm-maybe/AI-image-detector，先阅读模型卡并保存其标签映射与版本。

环境安装见[环境说明](../../docs/environment.md)。先从仓库根目录运行：

```powershell
python tools/check_environment.py --profile generation
python tools/run.py 04 --dry-run
```

### 操作步骤

1. 核对真实图来源及生成图参数，保存未加工输入，不把检测结果反过来当来源标签。
2. 先检测原始输入，再分别保存JPEG质量100、75和40的副本并检测。
3. 汇总两类输入各四种条件的全部标签分数，共八组结果，比较同一输入在处理前后的变化。

在环境确认后执行：

```powershell
python tools/run.py 04
```

核心程序：[lab.py](lab.py)。运行结果位于仓库根目录results/，每次运行日志与环境摘要位于results/runs/。

### 预期效果

得到原始输入与三档JPEG条件的分数表，以及六张JPEG副本。分数变化不预设方向：压缩可能改变已有特征，也可能引入新伪影。检测器返回标签是模型任务定义，不直接等于图像事实为真的概率。

### 本地实测状态

尚未完成本机检测器实测，且真实照片需由使用者提供来源和授权。原始图与压缩图的分数不得预填为示例事实；仓库提供记录结构和复核步骤。

### 结果分析与提交物

先讨论同图跨压缩条件的变化，再讨论真实图是否被误判。扩展评估时，应把相同原图的所有变体放在同一数据划分，避免其同时进入阈值选择集与测试集。
