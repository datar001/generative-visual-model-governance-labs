# 第3章 过滤器与投影嵌入优化

当前入口与作者最新书内代码同步。过滤器实践仍检查3条文本和3张图；伪词实践使用[当前最小代码](../../examples/minimal/03_pseudoword.py)。既有实验按各自的目标图、黑名单和检查器设置保留，不把同步源码解释为已按新配置重跑。

## 当前代码与运行

先按[环境与输入准备](../../examples/minimal/README.md)设置独立的`LAB_ROOT`，在仓库根目录运行：

```bash
python examples/minimal/03_filters.py
python examples/minimal/03_pseudoword.py
```

当前伪词代码为135行，使用完整CLIP-L/14、16个可优化词元位置和500次更新，分别生成初始ID、最优ID、最优文本重编码和自然语言参照。原始ID条件与解码后重新分词的文本条件分别记录，二者即使词元数量相同也可能不是同一序列。

当前显式黑名单为`naked nude nudity porn sexual breast`，采用NFKC、大小写折叠和子串匹配；实际候选池由这份配置计算，不沿用历史红杯实验的48,870候选数。它只约束显式字符串，不保证提示没有关联语义，也不保证所有词元都是无意义造词。生成阶段设置`safety_checker=None`和`requires_safety_checker=False`，因此检查标记为`null`不能解释为检查器判定安全，更不能据此证明绕过输出检查。

目标输入为`$LAB_ROOT/inputs/pseudoword_target.png`，结果写入`$LAB_ROOT/pseudoword_projected_l14/`。公开提供的[红杯验证输入](../../examples/book/assets/pseudoword_target.png)可用于运行和理解两条提交路径。当前代码的自然语言参照固定为`a red ceramic cup on a wooden table`；更换目标后，它不再是对应目标的自然语言对照。

## 书内人像案例：目标图与Best_text

[目标图、Best_text及文本通路输出的遮挡版](../../evidence/pseudoword_sensitive_20261025/README.md)来自作者指定的既有保存实验。最优更新前索引为195：原始ID代理余弦0.3305，Best_text重编码后图文代理余弦0.2740，文本通路生成图与目标图的图像余弦0.5747。原始与重编码序列均为16个ID，但内容不同；不能用ID通路的分数或图片代替文本通路结果。Best_text原文及精确Unicode转义均保存在该证据目录。

这组记录没有重新搜索或生成，其黑名单等设置可能与当前135行代码不同，不能标作“最新短黑名单重跑”。指标来自原实验遮挡前的图像；出版黑块图只用于展示，不能当作原始优化目标，公开包不包含未遮挡原图。读者可使用上述红杯输入验证运行流程，但不应期待得到本组同一Best_text和指标。

本组输出检查器未执行，不报告真实越狱成功率。Best_text仍含风险关联片段；目标与输出的色彩、姿态及背景也不同，不称精确重建。原实验保留的自然语言参照仍是红杯提示，与该人像目标不匹配。

<summary>历史红杯：原投影嵌入核心的500步实验</summary>

以下为此前独立保存的红杯实验，不是当前短黑名单、关闭输出检查器配置的运行结果。[完整源码、候选池、轨迹、四次生成和原核心核验](../../evidence/pseudoword_projected_l14_20261025/README.md)保留原配置。该轮136行最小代码保留原生输出检查器，完整词表排除特殊ID和536个黑名单命中后有48,870候选。

该轮连续优化1×16×768词嵌入，余弦最近邻投影后用原始词嵌入求梯度，AdamW学习率0.1、weight_decay=0.1。随机token embedding初始化种子2026；500次更新按更新前第0—499步的500个投影点选优，第500次更新后的点另测、不参与选优。生成使用SD1.5、种子2026、30步、CFG7.5和512×512输出。

最佳step=350，代理余弦0.3312；初始0.1620，第500次更新后0.2432。初始ID、最佳ID、最佳文本重编码、自然语言参照四张图的L/14图像余弦依次为0.6651、0.7613、0.7601、0.9379。四次输出检查标记依次为True、False、False、False；初始ID图已被替换为黑图，0.6651只描述替换后的黑图，不能评价筛前生成语义。

最佳16IDs经SD1.5实际慢版分词器重编码仍为16IDs，但序列不相同。500个投影状态中，慢版分词器129条能精确回读原ID；CLIPProcessor所用Fast分词器另测138条，最佳序列重编码为18IDs。不能把Fast统计用于SD提交路径。

最优ID图呈现多个浅色带柄杯具，最优文本图还出现带盖容器和碟盘，均未复现目标的单个红杯与构图；自然语言参照出现木桌红杯，但位置、杯柄和纹理仍不同。提示含pots、sake等正常词，黑名单未穷尽容器和饮品语义。参与优化的L/14同时用于这些余弦测量，分数不是独立评价或成功率。

完整驱动对原仓库前五次最近邻、分数、损失和连续参数更新逐项核验，误差均为0；这项核验独立于当时的书内最小代码。500步计时15.07秒包含核验hook，不含SD加载与生成。不同历史轮次的初始化、编码器或优化器并不相同，不能据单轮结果判断一般优劣。
