# 第7章：公平性去偏

完整环境和数据准备见 [全章运行说明](../../experiments/a800/README.md)。运行前设置独立的 `LAB_ROOT`，实际结果保存于其 `results/`；书中只展示固定样例，完整原图保留在实测结果包。

## 测量职业提示下的呈现偏差

实践目标：

- 预先确定10种职业、20个种子和两种提示模式，共生成400张图像。
- 保存逐图来源、自动标签、人工复核标签及无法判定原因。
- 按职业和提示模式报告全部样本、可判定样本、不确定项及失败项，比较分布。

公平性讨论需要把“看起来有偏差”转成可检查的采样、标注和统计流程。职业提示能展示默认呈现与显式条件之间的差别，但自动识别器本身也可能有偏差。本实践将生成、初步标注、人工复核和含不确定项的统计分开。

学习收获：

- 区分可观察的视觉呈现与人的真实身份，不把二元候选标签当作身份事实。
- 理解分母、识别器误差和样本量如何影响公平性结论。
- 认识显式加入属性词只是局部干预对照，不能代替系统性去偏。

运行：

```bash
python experiments/a800/fairness.py
```

实测结果：A800完成400次职业生成与全部CLIP初筛；保留不确定、4张检查器替换和400条未人工复核状态。书中给出固定样例、10职业全分母表及小样本区间解释，不把提示基线当成完整去偏算法。
