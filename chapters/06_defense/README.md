# 第6章：安全防御

完整环境和数据准备见 [全章运行说明](../../experiments/a800/README.md)。运行前设置独立的 `LAB_ROOT`，实际结果保存于其 `results/`；书中只展示固定样例，完整原图保留在实测结果包。

## 比较SLD开启与关闭

实践目标：

- 对非露骨成人泳装、衣着完整肖像和红杯三个提示，以三个种子分别设置关闭与STRONG，共完成18次配对生成。
- 对齐模型、提示、种子和步数，分列引导模式与输出检查标志。
- 记录语义、主体、服装与构图的变化，允许出现“未观察到差异”。

推理阶段防御会改变生成轨迹，其效果不应只被归纳为“有害内容变少”。本实践先用同一模型和初始随机性比较SLD关闭与开启，让读者观察干预位置、内容变化和输出检查信号之间的关系。

学习收获：

- 理解推理引导和生成后检查器属于不同环节。
- 使用成对实验评估干预，同时关注正常内容保持。
- 区分课堂观察与有独立风险标签的安全性能评估。

运行：

```bash
python experiments/a800/sld.py
```

实测结果：A800完成3场景×3种子×2模式=18次SLD配对生成。泳装种子2027两模式均被输出检查器替换，其余输出保留；图像改变与检查器替换分别统计，不报告色情抑制率。

## 加载预训练ESD权重观察风格擦除

实践目标：

- 核对官方Van Gogh ESD-x权重与SD 1.4基础模型的对应关系，保存版本与文件哈希。
- 对两条目标风格提示和两条普通内容提示，分别用三个种子进行原模型/擦除模型配对生成，保存24张图及参数。
- 说明目标风格变化、正常内容保持与观察边界，不能由少量示例推断普遍擦除效果。

概念擦除改变的是模型参数。本实践直接加载作者公开的ESD-x风格擦除权重，比较相同条件下原模型与编辑模型的输出，把学习重点放在权重配套、目标行为变化与无关内容保持，不再要求学员训练ESD。

学习收获：

- 区分完整UNet权重、LoRA适配器和完整生成管线；官方文件替换的是基础模型的UNet参数。
- 用相同基础组件、提示、种子和采样设置进行配对推理，避免把更换基础模型的差异当成擦除效果。
- 从输出观察理解ESD参数编辑的作用，不再编写教师网络、优化器或反向传播训练循环。

运行：

```bash
python experiments/a800/esd.py
```

实测结果：A800完成官方ESD/SD1.4的24张512×512、30步配对图；全部输出标记未触发。书中展示固定种子的4组图及每条件6图的CLIP描述性均值，明确不等于风格擦除成功率。
