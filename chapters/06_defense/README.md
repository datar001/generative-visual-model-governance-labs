## 比较SLD开启与关闭

### 为什么做

推理阶段防御会改变生成轨迹，其效果不应只被归纳为“有害内容变少”。本实践先用同一模型和初始随机性比较SLD关闭与开启，让读者观察干预位置、内容变化和输出检查信号之间的关系。

### 实践目标（应交付什么）

- 对两个日常海滩场景提示分别生成SLD关闭和STRONG配置的结果，共四张图。
- 对齐模型、提示、种子和步数，分列引导模式与输出检查标志。
- 记录语义、主体、服装与构图的变化，允许出现“未观察到差异”。

### 完成后应掌握什么

- 理解推理引导和生成后检查器属于不同环节。
- 使用成对实验评估干预，同时关注正常内容保持。
- 区分课堂观察与有独立风险标签的安全性能评估。

### 环境和输入

使用第2章生成环境，另下载Safe Stable Diffusion管线权重。SLD管线在本书固定的Diffusers 0.32.2中使用，不能把新版接口变化视为实验结果。显卡需容纳推理模型；低显存设备可使用已配置的注意力切片与CPU卸载。

环境安装见[环境说明](../../docs/environment.md)。先从仓库根目录运行：

```powershell
python tools/check_environment.py --profile generation
python tools/run.py 06 --case sld --dry-run
```

### 操作步骤

1. 检查模型、SafetyConfig和环境版本，保留输出检查器。
2. 对每个提示分别设置引导关闭和STRONG，其余参数相同，保存四张图与标志。
3. 按主体、语义、服装、背景及失败状态逐项对照；随后可增加WEAK或MAX作为拓展，另建实验条件。

在环境确认后执行：

```powershell
python tools/run.py 06 --case sld
```

核心程序：[sld.py](sld.py)。运行结果位于仓库根目录results/，每次运行日志与环境摘要位于results/runs/。

### 预期效果

得到两提示、两模式的四图对照。没有变化也应报告；两个日常提示不保证触发安全引导。应区分引导改变生成内容与输出检查器替换图像，不把后者误写成前者的独立效果。

### 本地实测状态

尚未完成本机四图实测，不能预填拦截率、内容变化幅度或近义词效果。仓库保留相同条件的运行入口及记录方式。

### 结果分析与提交物

若要报告安全性，应先定义风险类别、审核依据和独立测试集，同时测正常提示的语义与质量保持。本案例只负责建立受控观察方法。

## 观察风格概念擦除

### 为什么做

概念擦除把干预从推理配置推进到模型参数。只有同时观察目标概念变化和无关内容保持，才能理解“擦除得更强”为什么不一定意味着整体模型更好。本实践用艺术风格概念演示反向训练目标。

### 实践目标（应交付什么）

- 保存同种子的编辑前、编辑后图像、训练损失和编辑后的模型。
- 比较目标风格表现，并设计不含目标风格的保留提示对照。
- 用多个种子和近义表达复测，明确教学目标与完整论文复现的区别。

### 完成后应掌握什么

- 理解冻结教师与更新学生参数的作用，认识反向目标的构造。
- 区分优化损失下降、目标行为改变与概念被普遍移除。
- 识别参数编辑的显存和存储开销，以及效果与能力保持之间的权衡。

### 环境和输入

使用生成环境与CUDA设备。当前教学实现同时保留教师、学生和优化状态，需要明显多于单次推理的显存；本机6GB显存不足以完成该实现的完整训练。应先检查资源和模型存储空间，再在合适设备运行，不能把配置检查通过写成训练完成。

环境安装见[环境说明](../../docs/environment.md)。先从仓库根目录运行：

```powershell
python tools/check_environment.py --profile generation
python tools/run.py 06 --case esd --dry-run
```

### 操作步骤

1. 固定模型与种子，保存编辑前目标提示结果；确认教师冻结、学生仅更新指定交叉注意力参数。
2. 运行200步教学训练，逐步记录损失并保存编辑模型及同条件编辑后图。
3. 增加普通风景、未训练风格及多个种子的保留集，在原模型和编辑模型上成对复测。

在环境确认后执行：

```powershell
python tools/run.py 06 --case esd
```

核心程序：[esd.py](esd.py)。运行结果位于仓库根目录results/，每次运行日志与环境摘要位于results/runs/。

### 预期效果

得到before.png、after.png、训练日志和edited_model。代码用学生当前采样潜变量再加噪构造目标，是解释ESD反向目标的教学变体，不是论文全部训练采样与评测协议的复现。损失下降不保证概念在所有路径消失。

### 本地实测状态

尚未完成本机训练与生成对照，本机显存不足是当前实现的资源限制。书中不提供虚构的擦除成功图、训练耗时或成功率；需在适当设备完成目标与保留集验证。

### 结果分析与提交物

比较时同时记录目标风格减弱、无关内容质量变化及近义提示表现。只有一张编辑后图，不足以证明彻底擦除；如需研究级结论，应对齐原论文协议并给出完整复现差异。
